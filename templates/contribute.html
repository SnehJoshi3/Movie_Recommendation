How Contributions Work

1
Form Submission Your data is sent via HTTP POST to the Flask /contribute endpoint.
2
SQL INSERT Python executes a parameterized INSERT INTO contributions query — immune to SQL injection.
3
Persisted to SQLite Record is written to contributions.db and the 5 most recent entries appear in the live table below.
4
Dashboard Counter Updates The Contributed KPI on the Dashboard page reflects the new count in real time.

Database Schema — contributions

id INTEGER — Auto-increment PK
movie_name TEXT REQUIRED
tmdb_imdb_link TEXT REQUIRED
added_at TIMESTAMP — DEFAULT NOW
