Step 01

Data Cleaning & Pre-Processing

The raw 527,104-record TMDB CSV undergoes systematic cleaning before any ML operation. This is the most critical quality gate in the pipeline.

1

Null Value Removal

Rows missing title, genres, or overview are dropped using df.dropna(subset=[...]). These columns are mandatory for TF-IDF feature generation.

2

Duplicate Elimination

Exact duplicate titles are removed with df.drop_duplicates(subset='title') to prevent biased similarity scores from repeated records.

3

Feature Column Construction

A synthetic tags column is created by concatenating genres and overview — the sole input to the TF-IDF vectorizer. This reduces noise from irrelevant numeric columns.

4

Subset Selection (10K)

The top 10,000 movies by popularity are selected for the processed database to ensure O(n²) cosine computation remains tractable in memory.

5

Persistence to SQLite

The cleaned dataframe is written to movies_database.db via df.to_sql('movies', conn, ...) for fast retrieval by the Flask API.

Step 02

TF-IDF Vectorization

Term Frequency–Inverse Document Frequency (TF-IDF) transforms unstructured text metadata into a high-dimensional numerical matrix that machine learning algorithms can process.

Term Frequency (TF)

Measures how frequently a word appears in a movie's tags column relative to all words in that document. Common words like "the" receive naturally low TF weights.

TF(t,d) = count(t in d) / total words in d
sklearn.TfidfVectorizer

Inverse Document Frequency (IDF)

Penalizes words that appear across many movie overviews (e.g. "story", "film") and rewards rare, distinctive genre-specific terms like "cyberpunk" or "heist".

IDF(t) = log( N / df(t) )
max_features=5000

Resulting Matrix

Each movie becomes a row vector of 5,000 dimensions. A value near 1.0 means that term is highly distinctive for that film. A value of 0 means the term is absent.

Shape: (10,000 movies × 5,000 features)
Sparse CSR Matrix

Pickle Serialization

The fitted TfidfVectorizer and the resulting sparse matrix are saved as vectorized_data.pkl via Python's pickle module — avoiding re-computation on every Flask startup.

pickle.dump(tfidf_matrix, open('vectorized_data.pkl','wb'))

Step 03

Cosine Similarity

Once movies are represented as vectors, their semantic "closeness" is computed using the cosine of the angle between them — the fundamental distance metric in information retrieval.

Cosine Similarity Formula
cos(θ) = (A · B) / (‖A‖ × ‖B‖)

Interpreting the Score

A cosine score of 1.0 means two movies have identical tag distributions. A score of 0.0 means no shared vocabulary at all. Scores are bounded between 0 and 1 because TF-IDF values are non-negative.

Implementation in Flask

On each POST /recommend request, cosine_similarity(vectorized_data[idx], vectorized_data) computes similarity between the query movie row and all 10,000 rows in ~50 ms, then argsort()[-10:][::-1] retrieves the top 10 indices.
