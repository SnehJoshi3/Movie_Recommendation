Project Evolution

A visual development journey — from a Google Colab notebook to a full-stack AI recommendation system backed by 1.1M+ movie records.

Prototype Flask App Database Optimization Analytics
● Development Phases
Phase 1

Initial Prototype

The project started as a Google Colab experiment. A small movie dataset was loaded, cleaned, and used to build a basic content-based recommendation engine using cosine similarity on TF-IDF feature vectors.

  • Built a basic recommendation model inside Google Colab notebooks
  • Experimented with multiple TMDB movie datasets and feature combinations
  • Implemented cosine similarity on combined text features (genre, cast, overview)
  • Validated recommendation quality manually with test queries
Python Google Colab Pandas Scikit-learn TF-IDF Cosine Similarity TMDB Dataset
Phase 2

Flask Web Application

The notebook prototype was converted into a Flask web application, making recommendations accessible through a browser. A Jinja2 frontend was designed so users could search movies and instantly receive recommendations with poster images.

  • Integrated Flask backend serving recommendation results via POST requests
  • Built a Jinja2-powered HTML/CSS frontend with a movie search interface
  • Enabled user movie searches with autocomplete using the title list
  • Displayed top-10 similar movies with TMDB poster images and ratings
Flask Jinja2 HTML/CSS JavaScript TMDB Poster API Python
Phase 3

Database Integration

SQLite databases were added to persist movie metadata and community contributions. The backend structure was reorganized for maintainability, and a community contribution feature allowed users to submit new movie links.

  • Added SQLite database for persisting contributions and metadata
  • Built CRUD operations for the community contribution system
  • Organized Flask routes into logical grouped sections
  • Improved session management and data validation on form submissions
SQLite SQLite3 (Python) Flask CRUD Form Validation Database Design
Phase 4

Recommendation Optimization

Runtime cosine similarity was replaced with precomputed vectorized data serialized to a .pkl file. This eliminated expensive on-demand computation and reduced recommendation response time to near-instant.

  • Switched from runtime TF-IDF + cosine similarity to precomputed pickle vectors
  • Reduced recommendation latency from seconds to milliseconds
  • Serialized both movie metadata and vectorized features to .pkl at build time
  • Eliminated redundant computations on every user request
Pickle (.pkl) Precomputed Vectors Scikit-learn Performance Optimization Memory Management
Phase 5

Dashboard & Analytics

A full analytics suite was added, split across two dedicated pages. The Dashboard reads the entire 1.1M-record raw CSV via memory-efficient chunked streaming to produce accurate dataset-wide statistics. The Analysis page presents EDA on the 10K processed recommendation dataset.

  • Built an A-Z Dashboard with 10+ interactive Chart.js visualizations from raw CSV
  • Implemented chunked CSV streaming (100K rows/chunk) for memory-efficient stat computation
  • Added dedicated EDA Analysis page with 8 charts from the processed PKL dataset
  • Added contribution & community section with SQLite-backed submission tracking
  • Added this Project Evolution page documenting the development journey
Chart.js Pandas Chunked CSV EDA Data Visualization SQLite Flask Templates
